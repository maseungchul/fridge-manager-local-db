| 타입         | 사용 기준             | 예시                              |
| ---------- | ----------------- | ------------------------------- |
| `feat`     | 새로운 기능 추가         | `feat: 식품 등록 기능 추가`             |
| `fix`      | 버그 수정             | `fix: 식품 삭제 시 오류 수정`            |
| `docs`     | 문서만 수정            | `docs: 백로그 항목 추가`               |
| `refactor` | 기능 변화 없이 코드 구조 개선 | `refactor: 냉장고 조회 로직 분리`        |
| `test`     | 테스트 코드 추가/수정      | `test: 식품 등록 테스트 추가`            |
| `chore`    | 개발 환경, 설정, 잡무     | `chore: 초기 개발 환경 구성`            |
| `build`    | 빌드 시스템/의존성 변경     | `build: Spring Security 의존성 추가` |
| `ci`       | CI/CD 설정 변경       | `ci: GitHub Actions 배포 설정 추가`   |
| `style`    | 동작과 무관한 코드 스타일 변경 | `style: 코드 포맷팅 적용`              |
| `perf`     | 성능 개선             | `perf: 식품 조회 쿼리 최적화`            |
| `revert`   | 이전 커밋 되돌림         | `revert: 식품 삭제 기능 롤백`           |
