# 냉장고 관리 앱 요구사항


## 프로젝트 개요 및 목적

별도 클라우드 서버 없이 로컬 DB로 동작하는 냉장고 관리 앱이다.
실제 냉장고 구조를 반영한 도면에서 재료의 보관 위치를 확인하고, 유통기한·장보기·부부 간 데이터 공유를 관리한다.


## 기능적 요구사항

| 구분 | 내용 |
| --- | --- |
| 기본 사용 | 로그인 없이 기기 내 냉장고 1대를 관리하며, 데이터는 앱 재실행 후에도 유지한다. |
| 표시 언어 | 한국어·일본어를 지원하며, 설정에서 선택한 언어를 기기에 저장하고 현재 구현된 전체 화면에 적용한다. |
| 냉장고 도면 | 냉장실·냉동실·문·본체·칸·서랍을 등록·편집하고, 위치를 선택하면 해당 재료 목록을 표시한다. |
| 재료 관리 | 재료명·수량·메모·유통기한·위치를 관리하고, 등록·조회·수정·삭제·이동·소비 완료를 제공한다. |
| 영수증 인식 | 영수증을 카메라로 촬영해 구매 항목을 장본리스트에 임시 등록하고, 인식 결과를 수정할 수 있다. |
| 입고 처리 | 장본리스트 항목을 선택한 뒤 도면의 칸·서랍을 선택하고, 부족한 정보를 입력해 재료로 등록한다. |
| 장보기 관리 | 구매할 항목의 추가·수정·삭제·완료 처리를 제공하고, 구매 완료 항목을 장본리스트와 연결한다. |
| 자동 장보기 등록 | 유통기한을 기준으로 장보기 목록에 항목을 자동 등록한다. |
| 유통기한 알림 | 임박·만료 재료의 위치를 도면에 표시하고, 재료명·위치를 포함한 로컬 알림과 사용 재촉 알림을 제공한다. |
| P2P 공유 | 부부의 기기가 각자 관리한 데이터를 실시간 동기화 없이 주고받는다. 통신 방식은 별도 검토한다. |
| 충돌 처리 | 별도 화면에서 충돌 부분을 강조하고, 클릭하면 충돌 내용 중 하나를 선택해 최종 반영한다. |
| 백업·공유 | 설정에서 암호화된 백업 파일을 내보내거나 가져오고, 메신저로 공유할 수 있다. |


## 주요 정책 및 화면 흐름

- 표시 언어는 한국어를 기본값으로 하고 기기 언어와 별도로 설정에서 `한국어 / 日本語`를 선택한다. 선택은 저장 성공 후 즉시 반영하며 앱 재실행 후에도 유지한다. 저장된 값이 없거나 지원하지 않는 값·조회 실패이면 한국어로 시작하고, 변경 저장에 실패하면 기존 언어를 유지한 채 해당 언어로 오류를 안내한다. 설정은 기존 `expo-sqlite/kv-store`의 `settings.language` 키에 `ko / ja`로 저장하며 냉장고·재료 DB와 분리한다.
- 번역 문구는 `src/i18n/locales/ko.ts`·`ja.ts`에서 같은 키로 관리하고 화면에서는 `useTranslation()`의 `t()`로 참조한다. 하단 탭·더보기·설정·장보기·홈 도면·냉장고 등록/편집·재료 목록/추가/편집·이동 대기·범례·달력과 접근성 안내·알림 버튼까지 적용한다. 개수·이름 등은 `t('queue.title', { count })`처럼 문장 안의 치환값으로 전달하며 누락된 키·필수 치환값은 타입 검사에서 확인한다. 사용자가 입력한 냉장고 이름·재료명·수량·메모는 번역하지 않는다.
- 단·문·칸·좌우의 자동 위치명은 현재 언어로 도면을 생성할 때 구하고, 위치 ID와 재료 연결은 언어 변경 전후에 유지한다. 신규 냉장고의 기본 이름은 생성 당시 언어로 표시하고 입력되거나 저장된 이름은 언어를 바꾸어도 유지한다. 남은 기한은 한국어·일본어 모두 `D-N / D-DAY / D+N`으로 통일하며 기한 계산은 동일하다. 달력의 요일·연월·접근성 문구와 화면의 날짜 구분 기호만 언어에 맞추고, 날짜 저장값 `YYYY-MM-DD`와 시간대 없는 날짜 계산은 유지한다.
- 저장·검증 오류는 번역 키·치환값을 가진 `AppError`로 전달하고 화면에서 현재 언어로 표시한다. 기존 DB 트리거 문구는 표시 시 번역하며 DB 버전·스키마는 변경하지 않는다. 알 수 없는 시스템 오류는 화면별 번역된 실패 안내를 표시한다. DB 초기화에 실패하면 같은 방식으로 안내하고 재시도 버튼을 제공하며 DB를 사용하는 화면은 열지 않는다.
- 홈·장보기·더보기·설정·냉장고 등록/편집과 재료 목록·추가·편집·이동 대기 시트는 공통 헤더 규격을 사용한다. 상하 여백은 `spacing.xs`(6), 좌우 여백과 버튼·제목 영역 사이 간격은 `spacing.md`(16), 콘텐츠 기준 높이는 48, 기본 제목은 크기 20·줄 높이 26으로 통일한다. 설정·냉장고 등록·편집과 재료 시트의 헤더 아이콘은 크기 28로 표시하되 터치 영역은 48×48을 유지하고, 버튼이 없는 화면도 같은 최소 헤더 높이를 확보한다. 시스템 안전 영역과 시트 손잡이 영역은 별도로 유지하며, 기존 제목의 좌측·중앙 정렬은 각 화면의 역할에 맞게 유지한다. 냉장고 도면의 공통 크기 계산도 이 헤더 높이를 사용한다.
- 좌우 스크롤 안내와 재료 이동 완료 안내는 공통 `Toast`로 아이콘·문구·반투명 진한 바탕·둥근 모서리·페이드·자동 숨김을 공유한다. 기본 표시 시간은 페이드인 200ms·유지 2500ms·페이드아웃 200ms로 총 약 2.9초이며, 페이드는 네이티브 드라이버를 사용한다. 표시 위치·노출 이력과 홈 상태 정리는 각 호출자가 관리하며, 안내는 터치·스크롤을 가로채지 않는다. 콜백 변경으로 표시 시간을 다시 시작하지 않고, 안내 교체·제거 시 타이머·애니메이션과 늦은 완료 신호를 정리한다.
- 기본정보·내부설정·홈의 냉장고 도면에는 미리보기·프레임·손잡이·경첩·선택 영역의 그림자를 적용하지 않는다. 문 앞면과 본체 내부의 여닫기 음영도 사용하지 않으며, 선택 테두리는 일반 테두리로 표시한다.
- 현재 등록 대상은 일반 냉장고이며, 김치냉장고·뚜껑형 지원은 보류한다.
- 냉장고를 삭제하면 단·본체·문·칸을 DB 외래 키의 연쇄 삭제로 함께 제거한다. 재료는 자동 삭제 대상에서 제외한다.
- 최초 등록은 단별 문 개수(1~2개)로 배치를 직접 구성하고, 내부 설정에서 여는 방식(왼쪽·오른쪽 열림·서랍형)·문 수납 사용 여부·같은 단의 본체 연결·칸·냉장/냉동을 정한다. 세로 문 합치기와 작은 보조 포켓은 제외한다.
- 기본정보 도면에는 단 식별자와 단별 문 개수만 전달한다. 도면 왼쪽의 단 번호 문구와 해당 여백은 표시하지 않는다. 도면은 왼쪽, 문 개수 조절·단 삭제 버튼 영역은 오른쪽 끝에 배치한다. 냉장·냉동, 문 방향·서랍형, 문 수납, 본체 연결, 칸 설정은 기본정보 도면의 표시에 반영하지 않는다. 도면의 손잡이·색상·모서리·표시 비율도 내부설정 컴포넌트와 토큰을 공유하지 않고 독립 관리한다. 단계 이동 시 내부 설정값은 초안에 보존한다.
- 내부설정의 닫힌 냉장고 외곽선은 표시하지 않고 문끼리 맞닿는 경계선만 4px 그레이(`#c0c9cf`)로 표시한다. 맞닿는 선은 한쪽 문에서만 그린다. 닫힌 문은 민트·아이스블루 바탕의 명도를 조금 낮춰 외곽선 없이도 화면 배경과 구분하고, 미설정 상태는 중립색 바탕을 사용한다. 문 전면에 별도의 입체감용 하이라이트·음영은 적용하지 않는다. 직각 모서리·실제 문 간격·도면 크기는 유지하며 기본정보 도면이나 열린 내부 프레임에는 이 경계선·색상 규칙을 적용하지 않는다.
- 내부 설정 도면은 기본 정보와 같은 문 배치로 닫힌 상태에서 시작한다. 문을 누르면 보기 선택 버튼 없이 연결된 본체와 도어 포켓이 함께 열리며 화면 중앙으로 이동한다. 문 한 개의 본체와 포켓은 같은 너비·높이로 표시하고, 공용 본체는 연결된 문 개수만큼 너비를 합산한다. 포켓은 여는 방향에 맞춰 본체 왼쪽·오른쪽에 나란히 배치하고 세로 경첩 두 개로 연결한다. 문 앞면과 뒷면은 같은 경첩을 기준으로 반대 면을 드러내며 회전한다. 열고 닫는 동안에도 본체의 흰 프레임·칸·냉장실/냉동실 이름을 문 뒤에 계속 표시한다. 도어포켓의 흰 프레임·이름·수납함(수납이 없으면 X 표시)은 회전하는 문 뒷면에 계속 표시하고, 열림 완료·닫기 시작 시 단색 배경으로 바꾸지 않는다. 경첩은 문이 절반 이상 열려 뒷면이 드러난 뒤 서서히 표시하고, 닫을 때는 같은 진행값을 역으로 적용해 사라지게 한다. 본체와 같은 이동값으로 경첩의 연결 위치를 유지한다. 본체·포켓의 터치와 접근성 탐색은 문이 완전히 열린 동안에만 허용한다. 열린 본체의 `냉장실 / 냉동실` 이름과 `도어포켓` 이름은 내부 상단에 인쇄된 글씨처럼 두고, 칸 영역과 겹치지 않게 공간을 확보한다. 서랍 전면은 아래로 밀려 열린다. 스크롤 밖의 레이어에서 열림·이동을 함께 가감속하고 문이 완전히 열린 상태에서 도면 바깥 배경을 누르면 원래 자리로 복귀하며 닫힌다. 도면의 별도 `닫기` 버튼은 표시하지 않고, 도면 내부·경첩·하단 툴바 조작은 외부 닫기를 실행하지 않는다. 기본정보와 내부설정 도면은 표시 비율을 각각 가로:세로 1:2로 관리한다. 내부설정 도면은 화면 너비를 채우지 않고 최대 높이 540과 남은 공간 안에서 비율을 유지해 중앙에 배치한다. 중앙에 펼칠 때 작은 본체·도어포켓은 형태별 목표 높이와 표시 영역에 맞춰 크기를 조절하며, 중앙 보기 동안 주변 도면의 스크롤·터치·접근성 탐색을 막는다.
- 중앙의 본체·포켓을 각각 누르면 해당 영역을 선택해 하단 카테고리 툴바의 하위 설정으로 편집한다. 수납을 끈 포켓은 X 표시로 남겨 선택 후 툴바에서 다시 켤 수 있게 하고, 서랍형에는 포켓을 표시하지 않는다. 합치기·분리 후에는 연결된 본체·포켓 배치와 복귀 위치를 다시 계산한다. 보기 상태는 등록 초안과 분리해 도면을 닫아도 기존 입력을 유지한다.
- 중앙 위치는 헤더·툴바 사이의 확정된 레이아웃 크기로 계산하며, 하위 설정을 펼치거나 접어도 표시 영역의 크기가 같으면 위치를 유지한다. 하위 설정은 툴바의 배치 높이를 바꾸지 않고 별도 공간에 표시한다. 도면의 중앙 위치는 하위 설정의 최대 높이·간격을 항상 제외한 동일한 영역으로 계산해 메뉴를 열고 닫아도 유지하며, 접힌 툴바에 빈 예약 공간은 표시하지 않는다. 열린 도면의 여백을 중복 적용하지 않고 실제 테두리를 기준으로 경첩을 배치한다. 본체·포켓 사이에는 경첩과 양쪽 선택선이 겹치지 않을 간격을 확보하며, 이 간격은 닫힌 도면의 문·단 사이 간격에 영향을 주지 않는다.
- 기본정보·내부설정 화면은 상단 단계 표시와 아래 콘텐츠 사이에 동일하게 spacing.lg(24)의 간격을 둔다. 내부설정의 닫힌 도면은 상단 정렬하며 단계 표시·도면 자체의 패딩은 유지한다. 기본 정보·내부 설정 도면은 단 사이와 같은 단의 문을 여백 없이 붙여 배치한다. 도어와 본체 프레임은 모든 모서리를 직각으로 표시하며 내부 경계선은 한쪽에서만 그린다. 닫힌 문과 여닫는 문 앞면에는 선택 테두리·선택 그림자를 표시하지 않는다. 열기·열린 상태·닫기에서도 문 앞·뒷면과 본체·포켓 프레임의 직각 모서리를 유지하며 수납 없음 표시와 열린 내부의 선택 테두리에도 동일하게 적용한다. 테두리는 각 문의 실제 영역에만 그리고 열린 문의 원래 자리를 가로지르는 공통 테두리·그림자는 표시하지 않는다. 도면의 비율·크기와 기존 여백은 유지하고 남는 세로 공간은 아래에 둔다. 중앙 보기의 바깥 닫기는 최상단 제목·헤더 여백에서도 동작하며, 1단처럼 큰 도면이 헤더에 닿아도 제목을 눌러 닫을 수 있다. 기존 헤더 버튼은 그대로 조작할 수 있고, 문을 열고 닫는 중에는 제목 영역 닫기를 막는다.

- 문을 열기 전·후와 수납 사용 여부에 관계없이 본체·도어포켓은 설정한 모드의 색상을 유지한다. 냉장은 민트, 냉동은 아이스블루를 쓰며, 열린 내부는 흰 외곽 프레임 안에 닫힌 문보다 한 톤 진한 배경과 밝은 반투명 포켓을 배치한다. 본체·도어포켓 모두 좌우·하단의 흰 여백을 10px로 맞추고, 상단은 6px 프레임과 28px 이름 영역을 흰 바탕으로 표시한다. `냉장실 / 냉동실 / 도어포켓` 문구는 각 영역의 상단 중앙에 글자 크기 14px·굵기 700으로 표시하며 그 아래에서 모드별 색 배경을 시작한다. 본체 안쪽 색 배경의 모서리 반경은 12px, 도어포켓은 10px로 맞춘다. 본체 선택 배경의 반경 6px에 바깥 여백 6px를 더해 외곽과 선택 배경의 둥근 모서리 중심을 맞춘다. 수납을 끈 포켓도 이름과 X 표시 영역을 분리하고 동일한 여백과 모서리 반경을 적용한다. 도어 외곽과 선택 테두리는 직각을 유지한다. 선반·포켓 테두리·좌우 구분선·수납 없음 X선까지 같은 모드 색상을 사용한다. 편집할 본체·도어포켓 전체의 선택 상태는 모드에 맞는 테두리로 표시하고, 칸 선택은 각 칸의 선택 배경으로 표시한다. 미설정 상태는 기본 배경과 중립 회색 선택 표시를 사용한다.
- 내부설정의 닫힌 문은 연결된 본체의 설정에 따라 선택 여부와 관계없이 모드별 색·그림·이름을 표시한다. 냉장은 민트색·찬 공기 그림, 냉동은 아이스블루·눈송이로 표현하고 중앙 그림 아래에 `냉장실 / 냉동실`을 표시한다. 문 상·하단의 장식 아이콘은 표시하지 않는다. 작은 문은 중앙 그림·글씨 크기를 줄이며, 서랍형은 위쪽 손잡이와 인쇄가 겹치지 않게 한다. 그림과 이름은 문 앞면과 함께 회전하고 합친 본체의 양쪽 문은 같은 모드로 표시한다. 미설정 상태는 기본 색으로 표시하고 이전 모드의 그림은 남기지 않는다. 열린 본체에는 `냉장실 / 냉동실`, 포켓에는 `도어포켓` 이름만 표시하며 별도의 원형 모드 배지는 사용하지 않는다. 이름이 있는 흰색 상단과 프레임 여백을 포함한 내부 전체를 눌러 해당 본체·포켓을 선택할 수 있다.
- 내부 설정의 전체 도면 화면에서는 툴바를 표시하지 않는다. 문이 완전히 열린 동안에만 하단 카테고리 툴바를 표시하고, 열고 닫는 중에는 숨기며 터치·접근성 탐색을 막는다. 이동 중에도 툴바 공간을 유지해 도면 위치가 튀지 않게 한다. 본체에는 보관 모드·여는 방식·칸 구성과 합치기/분리 버튼을, 도어포켓에는 칸 구성과 문 수납 스위치를 표시한다. 합친 본체의 여는 방식은 비활성화한다. 본체 연결 카테고리는 두지 않고 분리된 본체는 합치기, 합쳐진 본체는 분리 버튼으로 즉시 동작한다. 이웃이 없으면 합치기를 비활성화하며, 서랍형·도어포켓에서는 합치기/분리를 숨긴다. 카테고리의 열림 상태는 선택 대상을 바꿔도 보존하되 해당 대상에서 사용할 수 없으면 감춘다. 기기 뒤로가기·접근성 닫기는 먼저 하위 설정을 접고, 다음에 중앙 보기를 닫는다.
- 별도 내부 설정 버튼·모달·축소 미리보기는 사용하지 않는다. 하위 설정은 도면 계산에서 별도로 제외한 공간에 한 줄로 표시하고 툴바의 실제 배치 높이에 더하지 않는다. 메뉴를 접으면 카테고리 버튼만 표시하고 빈 툴바 여백을 남기지 않는다. 하위 영역에는 상위 툴바와 같은 배경색을 적용하고 상위 버튼과 외곽선이 겹치지 않도록 간격을 둔다. 그 사이 검은색 삼각형 화살표로 부모·자식 관계를 표시하되 화살표도 양쪽 외곽선과 닿지 않게 하며 하위 영역까지의 간격은 6으로 맞추고 별도 제목·닫기 줄은 두지 않는다. 보관 모드 카테고리는 온도계 아이콘을 유지하고 하위 냉장 선택에는 바람 아이콘을 사용한다. 한 번에 한 카테고리만 펼치며 같은 버튼을 다시 누르면 접는다. 하위 버튼은 글씨·아이콘·내부 여백에 필요한 너비만 차지하고 남은 가로 공간을 채우도록 늘리지 않는다. 글씨를 한 줄로 유지하고 너비를 줄여 줄바꿈하지 않으며, 공간이 부족한 버튼 행은 좌우 스크롤로 확인한다. 좌우 분할 선택에도 같은 방식을 적용한다. 가로 스크롤 표시줄은 버튼 아래 16의 별도 여백에 표시해 버튼과 겹치지 않게 한다. 보관 모드는 냉장/냉동, 여는 방식은 왼쪽/오른쪽/서랍형, 문 수납은 별도 하위 선택지 없이 툴바의 문구 옆 스위치로 바로 변경한다. 칸 구성은 칸 개수 조절과 분할 없음/좌우 2칸을 같은 가로 스크롤 한 줄에 표시한다. 기본정보·내부 설정의 증감 조절은 공통 컨트롤을 사용한다. 밝은 아이보리·옅은 회색 테두리의 128×44 캡슐 안에 − / 개수 / +를 묶고 내부 구분선은 표시하지 않는다. 기본정보는 N도어, 내부 설정은 N칸으로 표시한다. 좌우 버튼은 각각 44의 터치 영역을 확보하고 누른 부분만 옅은 민트로 표시한다. 별도 칸 번호 버튼·분할 제목은 표시하지 않으며 본체 도면을 눌러 편집할 칸을 선택한다. 칸 구성에서 선택한 본체 칸은 사각 테두리 대신 기존 본체의 반투명 합성색을 고정한 불투명 배경으로만 강조하고 마커는 표시하지 않는다. 본체 수납 영역의 내부 여백은 구분선 중심까지의 반간격인 6으로 상하좌우 동일하게 맞추고, 칸 사이에는 구분선과 양옆 여백을 포함한 12의 공간을 따로 확보해 실제 수납 칸을 같은 높이로 배분한다. 선택 배경은 각 수납 칸의 내부 면을 모서리 반경 6으로 채운다. 좌우 2칸도 각각 눌러 선택하고 선택한 위치의 배경만 강조한다. 첫 칸·중간 칸·마지막 칸 모두 같은 선택 배경 크기와 여백 기준을 사용하고 구분선 주변은 칠하지 않는다. 개별 위치 선택 테두리는 유지한다. 펼친 상태에서 카테고리만 바꿀 때는 같은 툴바 높이를 유지하며 변경은 초안에 즉시 반영한다.
- 칸 이름을 직접 입력하지 않고 본체·도어포켓 도면에는 칸명을 표시하지 않는다. 하위 설정·접근성 안내·내부 데이터에는 위에서부터 `위에서 N번째 칸`으로 자동 지정하고, 좌우 분할은 `왼쪽 / 오른쪽`으로 구분한다. 칸 이름은 DB에 저장하지 않고 `sort_order`로 생성하며, 본체 합치기·분리 후에도 현재 순서를 기준으로 표시한다.
- 기본 흐름: `첫 실행 → 냉장고 등록 → 홈 도면 → 위치 선택 → 재료 목록·관리`.
- 홈의 닫힌 도면에는 함께 열리는 본체·연결 도어포켓의 합계 배지를 한 묶음으로 표시하고, 열린 도면에는 본체·도어포켓의 각 칸과 좌우 분할 위치별로 표시한다. 닫힌 홈 도면의 배지는 보관모드 아이콘 아래에 8 간격을 두고 손잡이 반대편 상단에 배치한다. 세로 손잡이 영역을 제외한 폭 안에서 세로로 나열하며, 서랍형은 상단 가로 손잡이 아래의 왼쪽에 배치한다. 합친 본체의 합계는 첫 번째 문에 한 번만 표시하고, 아이콘과 배지는 문 앞면과 함께 움직인다. 열린 내부 도면은 본체 칸과 도어포켓 수납함 전면 안의 왼쪽 상단에 여백 4를 두고 배치한다. 상태별 색상 배경의 배지를 하나의 캡슐 형태로 묶는다. 묶음의 바깥 모서리만 반경 10으로 처리하고 내부 경계는 도면 배경이 보이는 1 간격으로 구분하며, 상태가 하나뿐이면 기존 캡슐 형태로 표시한다. 일반 재료 수는 녹색, 유통기한 주의 수(D-2부터 당일)는 주황색, 기한 경과 수는 빨간색 배경을 사용하며 일반·유통기한 주의·경과는 중복 집계하지 않는다. 배지의 아이콘과 숫자는 흰색으로 표시하고 각 숫자 왼쪽에 크기 14의 Material 상태 아이콘을 둔다. 일반은 `circle-outline`, 주의는 `clock-outline`, 경과는 `alert-circle-outline`을 사용한다. 각 상태는 최소 높이 20·가로 안쪽 여백 5·세로 안쪽 여백 2로 표시하고 상태 사이에는 1 간격을 두고 묶음의 안쪽 여백은 두지 않는다. 범례는 숫자를 제외하고 도면과 같은 상태색 배경·흰색 아이콘을 사용하며, 아이콘 크기를 22로 키워 표시한다. 홈·본체·도어포켓은 아이콘과 숫자 간격, 글자 크기를 공통으로 사용한다. 날짜 미입력은 일반 재료 수에 포함하고 수량 문자열은 합산하지 않는다. 빈 위치·0건인 배지와 냉장고 등록·편집 도면에는 표시하지 않는다. 닫힌 홈 문은 일반·유통기한 주의·경과 순서로 위에서 아래로 병합하고 아이콘과 숫자의 왼쪽을 맞춘다. 열린 내부의 본체 칸·도어포켓은 같은 순서로 왼쪽에서 오른쪽으로 한 줄 병합한다. 0건 상태를 제외한 뒤 남은 상태를 연결한다. 홈 내부도면은 세 상태가 모두 최대 표시 건수여도 들어가는 최소 폭을 재료 유무와 관계없이 확보하고, 넘치는 폭은 기존 좌우 스크롤로 탐색한다. 배지 개수에 따라 칸·포켓 전면의 높이를 바꾸지 않으며, 포켓 전면은 기존 높이 비율을 유지한다. 100건 이상은 `99+`로 표시하되 접근성 안내에는 실제 건수와 기한 상태를 제공한다. 저장 성공 직후 도면의 열림·선택 상태를 유지하며 배지를 갱신하고, 홈 재진입·앱 재실행 시 DB의 재료를 조회해 복원한다. 자정과 앱 복귀 때 현지 날짜로 기한 분류를 갱신한다.
- 홈의 하단 탭바 바로 위에 도면과 겹치는 접이식 도구 버튼을 띄운다. 툴바의 별도 배경 띠·상단 경계선·점유 공간은 두지 않으며 펼침·접힘으로 도면의 표시 높이·크기·스크롤 위치를 바꾸지 않는다. 기본 상태는 펼침이며 처음부터 범례와 이동 대기 버튼(대기 재료가 있을 때)을 표시한다. 오른쪽 끝의 `menu-close`를 누르면 오른쪽으로 접고, 접힌 상태의 `menu-open` 버튼을 누르면 왼쪽으로 펼친다. 메뉴 버튼은 화면 오른쪽 끝에서 8 간격을 둔 40×40 원형으로, 진한 녹색 배경·테두리와 테마의 흰색 아이콘·그림자로 구분한다. 도구는 메뉴 바로 왼쪽에 일정한 간격을 두고 오른쪽 정렬한다. 최소 높이 36의 캡슐 버튼 안에 아이콘·문구를 가로로 표시한다. 이동 대기·범례는 동일한 아이보리 배경과 녹색 글자·테두리, 은은한 그림자를 사용한다. 도면 자체에는 그림자를 추가하지 않고 등록·편집 툴바는 유지한다. 도구 버튼만 실측 너비를 기준으로 240ms 동안 가로 슬라이드·페이드하며 네이티브 드라이버를 사용한다. 접힌 도구는 터치·접근성에서 제외하고 메뉴 버튼만 남긴다. 버튼 사이의 빈 영역은 도면 터치·스크롤을 가로채지 않으며 버튼 그림자가 잘리지 않게 슬라이드 영역 안에 여유를 둔다. 하단 안전 영역은 탭바에서 한 번만 적용하고 홈 본문에는 중복 여백을 두지 않으며, 본문과 탭바는 기존 크림 계열 배경으로 연결한다. 하단 탭바와 제목·도구 버튼은 고정한다. 전환 중 연속 토글·도구 실행·문 전환·칸 선택을 막으며 전환은 탭바 배치·선택 가능 상태에 영향을 주지 않는다. 홈 전체 도면의 상단·하단에 각각 10 간격을 스크롤 콘텐츠로 두고 별도 툴바 예약 여백은 두지 않는다. 닫힌 전체 도면과 열린 내부 도면의 넘치는 높이는 상하 스크롤로 탐색하며 열린 도면의 좌우 스크롤도 유지한다. 화면 크기 변화로 표시 범위를 벗어난 스크롤만 보정하고 문을 닫을 때는 배경 도면의 실제 위치로 복귀한다. 재료 시트·대기 시트·범례가 열린 동안에는 도구의 펼침 상태를 유지한 채 표시·입력·접근성을 숨기고 종료 후 복원한다. 범례 버튼을 누르면 화면 중앙에 `일반 / 주의 / 경과` 세 가지 재료 라벨의 의미를 설명하는 팝업과 암전 배경을 표시한다. 범례 설명의 날짜 항목은 `유통기한`으로 표기한다. 범례에는 숫자 없이 상태색 배경·흰색 아이콘 배지를 표시하고 타이틀과 같은 행에서 중앙 정렬하며, 설명은 타이틀 아래에 왼쪽을 맞춰 배치한다. 항목은 냉장·냉동·일반·주의·경과 순서로 표시하며 냉장·냉동은 제목과 도면의 모드별 색상을 사용하는 바람·눈송이 아이콘만 표시하고 별도 설명은 두지 않는다. 팝업 기본 높이는 340으로 설명이 약 3개 보이도록 하고, 작은 화면에서는 안전 영역 안으로 제한한다. 제목은 고정하고 설명 목록만 세로 스크롤하며 스크롤 표시줄을 제공한다. 팝업 바깥 터치·뒤로가기·접근성 닫기는 범례만 닫고 도면의 열림·선택·스크롤 상태를 유지한다.
- 닫힌 문의 냉장·냉동 표시는 공간 이름 없이 작은 아이콘만 손잡이 반대편 상단에 표시한다. 왼쪽 열림은 왼쪽 위, 오른쪽 열림은 오른쪽 위에 배치하며, 상단 중앙에 가로 손잡이가 있는 서랍형은 왼쪽 위에 표시한다. 홈·등록·편집에서 합친 본체의 보관모드 아이콘은 첫 번째 문의 왼쪽 상단에 한 개만 표시하며 다른 문에는 중복 표시하지 않는다. 빈 본체와 문 전환 중에도 같은 기준을 사용한다. 합치지 않은 본체는 각 문에 아이콘을 표시한다. 문을 여닫는 동안 앞면과 함께 이동하고 아이콘 크기는 유지한다.
- 수동 등록 재료는 이름·수량·유통기한·보관 위치를 저장한다. 이름과 수량은 공백만 있는 값을 제외한 1~50자로 제한하고, 수량은 `2개`·`반 통`처럼 단위를 포함한 문자열을 사용한다. 유통기한은 선택 입력이며 실제 날짜만 `YYYY-MM-DD`로 저장한다. 위치는 기존 칸 ID와 좌우 번호(분할 없음·도어포켓 0, 왼쪽 1, 오른쪽 2)로 구분하고 같은 이름도 별도 재료로 등록할 수 있다. 수납을 끈 문이나 서랍형 문의 숨긴 포켓에는 등록하지 않는다. 재료가 있는 위치의 삭제·분할 변경과 해당 포켓의 수납 끄기·서랍형 전환은 재료를 먼저 이동·삭제한 후 허용한다.
- 홈에서 문이 완전히 열린 뒤 칸을 누르면 선택한 위치의 재료 목록을 네이티브 바텀시트로 표시한다. 목록은 절반 높이에서 시작하고 손잡이를 위로 끌면 확대하며 아래로 끌면 닫힌다. iOS는 커스텀 비율 대신 시스템 기본 medium·large 단계를 사용하고 Android는 시스템의 부분·전체 펼침을 사용한다. 칸 ID와 좌우 번호로 조회하고, 유통기한이 빠른 순서로 재료명과 그 오른쪽 수량을 같은 크기 17로 표시하고, 남은 기한을 같은 첫 줄의 오른쪽 끝에 D-N·D-DAY·D+N으로 기준선을 맞춰 표시한다. 메모가 있으면 재료명 아래에 기존 수량과 같은 크기 15로 표시하고, 메모가 없으면 해당 줄을 생략한다. 기한이 3일 이상 남은 재료는 녹색, D-2부터 당일까지는 주황색, 기한 경과는 빨간색으로 표시해 재료 배지 색과 통일하고, 날짜가 없는 재료는 뒤에 두며 유통기한 미입력으로 표시한다. 남은 일수는 현지 달력 날짜로 계산한다. 목록 제목은 패널 가로 중앙에 정렬하며 왼쪽에 추가 버튼과 같은 너비의 빈 영역을 확보한다. 제목 오른쪽에 크기 28의 `plus` 아이콘과 48×48 터치 영역으로 `재료 추가` 버튼을 표시하고 하단 추가 버튼은 두지 않는다. 빈 목록에는 안내를 표시하고 조회 중·실패 상태는 빈 목록과 구분하며, 조회 중·실패 시 추가 버튼을 비활성화한다. 실패하면 시트에서 재시도한다. 목록·추가 시트에는 취소·닫기 버튼을 표시하지 않으며, 시트 종료 시 칸 선택을 해제하고 도면의 열림·크기는 유지한다. iOS 재료 패널은 Expo UI의 시스템 medium·large 시트를 사용하고, 0.5·1.0 비율의 커스텀 detent를 사용하지 않는다. iOS 재료 패널은 바깥 배경 터치로 닫히지 않고 아래로 스와이프해 닫는다. medium·large와 추가 화면 최대화 단계 모두 시스템 배경의 닫기 동작을 사용하지 않으며, 열린 동안 도면과 하단 탭의 조작을 함께 막는다. 별도 어두운 배경 레이어·앱 전역 배경 래퍼·닫기 감지용 UIKit 화면은 추가하지 않는다. 작은 스와이프나 취소에는 선택 표시를 유지하고, 시스템 시트의 종료 신호(onDismiss)에서 패널·칸 선택·배경 입력 차단을 함께 정리한다. 표시 여부 변경 신호만으로 선택을 해제하지 않으며, 중복 종료 신호는 무시한다. 시트가 열린 동안 배경 도면의 터치·접근성 탐색과 좌우 이동 안내는 막는다.
- `재료 추가`를 누르면 냉장고 등록 단계와 같은 240ms 좌우 슬라이드로 등록 폼으로 전환하고 패널 높이도 기존 크기에서 부드럽게 최대화한다. 높이 전환 중에는 기존 단계와 최대화 단계를 함께 유지하고 전환이 끝난 뒤 추가 화면을 최대화 높이로 고정한다. 추가 화면에서는 입력 포커스·키보드 표시 여부에 관계없이 최대화 높이만 허용하며 아래로 스와이프해 닫을 수 있다. 뒤로가기·저장 성공 후 목록으로 돌아가면 추가 화면으로 이동하기 전에 사용자가 선택했던 높이(절반 또는 최대화)를 복원하고 다시 스와이프로 크기를 바꿀 수 있다. 상단 드래그 바는 시스템 기본 표시기를 숨기고 고정 회색(#C4C4C4)으로 표시하며, 스와이프 동작은 네이티브 시트가 처리한다. 뒤로가기·저장 성공 시에는 반대 방향으로 목록에 돌아간다. 제목·상단 버튼·본문을 한 페이지로 함께 이동하고 회색 드래그 바는 상단에 고정한다. 실제 시트 너비로 이동 거리를 계산하고 전환 중에는 두 페이지를 유지하며 입력·연속 이동·저장·시트 닫기와 비활성 페이지의 터치·접근성 탐색을 막는다. 보관 위치는 선택한 칸으로 자동 지정하되 목록·추가 시트에 브레드크럼과 보관 위치 안내는 표시하지 않는다. 재료명·수량은 필수, 메모·유통기한은 선택 입력으로 표시한다. 메모는 앞뒤 공백을 제거해 저장하고, 미입력·공백만 있는 값은 NULL로 저장한다. 재료명·수량·메모 입력에 포커스를 줘도 폼의 스크롤 위치를 자동으로 바꾸지 않으며 사용자가 직접 스크롤한다. 유통기한을 누르면 키보드를 닫고 iOS·Android 공통의 커스텀 달력을 화면 중앙에 표시한다. 달력은 앱의 크림색 바탕·녹색 강조를 사용하고 안전 영역 안에서 최대 너비 360으로 표시하며, 작은 화면에서는 내용만 스크롤한다. 입력칸 좌표 측정·네이티브 날짜 선택기·고유 크기 축소·플랫폼별 초기값 이벤트 보정은 사용하지 않는다. 미입력 상태에서는 오늘이 있는 달을 보여주되 선택된 날짜는 없으며, 오늘은 테두리로만 표시하고 실제 선택값은 녹색 배경으로 구분한다. 날짜 칸을 직접 누르면 오늘이나 기존 선택값과 같은 날짜도 즉시 입력하고 확인 버튼 없이 닫는다. 이전·다음 달 이동과 연도·월 바로 선택을 지원하며, 월을 바꿔도 여섯 주 영역의 높이는 유지한다. 바깥 터치·닫기 버튼·뒤로가기·접근성 닫기는 입력을 바꾸지 않고 달력만 닫는다. 달력을 열거나 달·연도를 이동하는 것만으로 날짜를 입력하지 않는다. 선택과 닫기는 한 번만 처리하며, 입력칸의 선택 해제 기능은 유지한다. 달력 표시를 위해 폼 배치나 패널 높이를 바꾸지 않으며 별도 크기 측정·종료 대기·레이어 페이드 제어를 두지 않는다. 시트의 제목과 상단 아이콘은 높이 48을 기준으로 세로 중앙에 정렬하고, 제목 영역 아래 구분선까지의 여백은 냉장고 등록 화면과 같은 spacing.xs(6)으로 맞춘다. 재료 추가 제목은 패널 가로 중앙에 정렬한다. 폼의 왼쪽 뒤로가기는 목록으로 돌아가며 입력은 같은 시트 안에서 유지한다. 오른쪽에는 냉장고 등록과 같은 크기 28의 `checkbox-marked-circle-plus-outline` 아이콘과 48×48 터치 영역으로 `재료 등록` 버튼을 표시하고 하단 저장 버튼은 두지 않는다. 필수 입력이 없거나 날짜를 선택 중이면 등록을 비활성화하고, 저장 중에는 아이콘 대신 로딩을 표시한다. 저장 성공 시 `알림` 제목과 `재료를 등록했습니다.` 본문, `확인` 버튼을 표시한다. 알림 확인 전까지 중복 등록·입력 변경·이전 이동·시트 닫기를 막고, `확인`을 누르면 해당 위치의 목록으로 돌아가 다시 조회하며 전환이 끝난 후 입력을 비우고 잠금을 해제한다. 저장 실패 시 오류와 입력을 유지해 재시도한다. 저장 중에는 중복 저장·입력 변경·시트 닫기·이전 이동과 스와이프 닫기를 막는다. 시트를 종료하면 저장하지 않은 입력은 버린다.
- 재료 목록의 항목을 누르면 추가와 같은 폼·240ms 좌우 전환·최대화 패널을 사용해 `재료 편집`을 연다. 기존 재료명·수량·메모·유통기한을 채우고 같은 필수 입력·날짜 선택·저장 잠금을 적용한다. 오른쪽 저장 버튼은 냉장고 편집과 같은 크기 28의 `checkbox-marked-circle-outline` 아이콘과 48×48 터치 영역으로 표시하고 접근성 이름은 `재료 수정 저장`으로 제공한다. 기존 재료 ID·보관 위치·등록 건수를 유지하며 기본 정보만 수정하고, 다른 재료는 변경하지 않는다. 수정 성공 시 `알림` 제목과 `재료를 수정했습니다.` 본문을 표시하며 확인 후 목록을 다시 조회해 정렬·표시를 갱신한다. 홈 배지도 같은 ID의 재료를 교체해 기한 상태를 즉시 갱신한다. 실패하면 편집 모드·입력을 유지해 재시도하고, 저장하지 않고 뒤로가면 수정은 버린다. 편집을 종료한 뒤에는 편집 전에 작성하던 추가 초안을 복원해 편집 값이 새 재료에 섞이지 않게 한다.
- 재료 목록의 항목을 왼쪽으로 밀면 오른쪽에 이동목록 담기·삭제 아이콘 버튼을 표시한다. 버튼은 크기 48·모서리 반경 24의 원형으로 만들고, 담기는 옅은 민트 배경과 녹색 `clipboard-arrow-left-outline` 아이콘, 삭제는 옅은 로즈 배경과 진한 붉은색 휴지통 윤곽 아이콘을 사용한다. 누르는 동안에는 기존 공통 버튼의 피드백을 적용한다. 노출 영역은 너비 144·목록과 같은 배경색으로 두고 버튼 사이와 좌우에 16의 여백을 확보하며, 접근성 이름은 재료명과 `이동목록에 담기 / 삭제`로 제공한다. 한 번에 한 항목만 열고, 오른쪽으로 밀기·항목 터치·패널 내부의 제목·빈 영역 터치·세로 스크롤·추가 또는 편집 이동 시 닫는다. 패널 내부 터치는 작업 버튼만 숨기고 패널·선택 위치·높이를 유지하며, 항목·작업 버튼의 터치와 네이티브 스와이프를 가로채지 않는다. 패널 바깥 터치에는 작업 버튼을 숨기는 동작을 연결하지 않는다. 가로 이동은 네이티브 가로 스크롤의 방향 고정과 닫힘·작업 버튼 전체 너비의 스냅으로 처리해 패널 크기 조절과 구분한다. 가로 이동을 시작한 뒤 작은 상하 움직임이나 JS 터치 취소로 작업 버튼이 사라지지 않게 하며, 네이티브 이동 목적지에 따라 열림을 확정한다. 세로 스크롤과 시트의 위아래 이동은 유지하고, 끝까지 밀어도 자동 삭제하지 않는다. 삭제 버튼이나 접근성의 `재료 삭제` 동작을 실행하면 `경고` 제목으로 재료명·복구 불가 안내와 `취소 / 삭제`를 표시한다. 확인·삭제 중에는 중복 요청·추가·편집·시트 종료를 막는다. 취소하면 데이터를 유지하고, 확인하면 ID·칸 ID·좌우 번호가 일치하는 재료 한 건만 삭제한다. 성공하면 목록과 홈 배지를 즉시 갱신하고 도면의 열림·선택·시트 높이는 유지한다. 실패하면 오류를 알리고 기존 목록을 유지해 재시도한다.
- 재료 단일·단체 이동은 임시이동목록으로 통합한다. 별도 수집·목적지 선택 모드 없이 여러 칸의 재료를 스와이프 담기 버튼이나 접근성의 `이동목록에 담기` 동작으로 모은다. 담기는 시트를 닫거나 DB 위치·배지를 변경하지 않으며, 담긴 행의 재료명 앞에 녹색 `clipboard-check-outline` 아이콘을 표시하고 담기 버튼은 `clipboard-check-outline` 아이콘으로 바꿔 비활성화한다. 중복은 재료 ID로 판단하고, 이름이 같은 별도 등록 건은 각각 담을 수 있다. 이름에 번호를 자동으로 붙이거나 수량·유통기한을 합치지 않는다. 임시목록은 앱 공통 메모리 상태로 유지하며 시트 닫기·탭 이동·홈 재진입·프로세스가 유지된 백그라운드 복귀 시 보존하고, 앱 프로세스를 다시 시작하면 초기화한다. 담긴 재료를 수정하면 최신 정보를 표시하고, 삭제에 성공하면 임시목록에서도 제거한다. 홈 전체 조회 성공 시 존재하지 않는 재료 ID만 정리하고 조회 실패로 목록을 비우지 않는다.
- 홈 도면의 펼친 툴바는 대기 건수와 무관하게 범례 오른쪽에 `clipboard-text-outline` 아이콘과 `이동 대기` 버튼을 표시한다. 범례와 동일한 아이보리 캡슐 버튼과 은은한 그림자를 적용한다. 대기 재료가 있으면 이동 대기 아이콘 오른쪽 상단에 숫자 없는 녹색 점 배지를 겹쳐 표시하고, 툴바를 접으면 같은 배지를 여는 버튼 아이콘 오른쪽 상단에 표시한다. 배지는 버튼·도면 크기에 영향을 주지 않으며, 대기 목록이 비면 사라진다. 누르면 기존 대기 목록을 재사용하는 medium·large 네이티브 시트를 열어 출발 위치 확인·개별 해제·전체 비우기를 제공하고, 0건이면 재료 목록에서 왼쪽으로 밀어 담는 방법을 안내한다. 홈에서 연 시트에는 목적지 이동 버튼을 두지 않는다. 시트가 열린 동안 배경 도면·범례·진입 버튼·하단 탭의 입력을 막고, 네이티브 종료 후 도면 열림·선택·스크롤을 유지한 채 입력을 복원한다. 재료 시트·범례가 열린 동안 진입 버튼을 숨기고 도면 전환 중에는 입력만 막는다.
- 이동 대기 재료가 한 건 이상이면 재료 목록 제목 아래에 `이동 대기 N개` 확인 버튼과 `여기로 이동` 버튼을 표시한다. 확인 버튼은 연한 녹색 캡슐 배경에 녹색 아이콘과 문구를 표시한다. 이동 버튼은 녹색 캡슐 배경에 흰색 `clipboard-arrow-down-outline` 아이콘과 문구를 표시하고, 이동 중에는 아이콘 대신 로딩 표시를 사용한다. 확인 버튼은 같은 시트 안에서 240ms 좌우 전환으로 임시목록을 열고 현재 목록의 높이를 유지한다. 재료 목록과 임시목록은 세로 스크롤 표시줄을 제공한다. 임시목록은 출발 위치별로 묶고, 단·같은 단의 영역·본체/도어포켓·위에서 몇 번째 칸·좌우 분할 방향의 경로와 재료명·수량·메모·실제 유통기한을 표시한다. 메모는 재료명 아래에 표시하고 유통기한은 그 아래에 표시하며, 유통기한 색상은 재료 목록과 같은 상태색을 사용하고 미입력은 회색으로 표시한다. 단·칸 번호는 위에서부터, 같은 단의 영역 번호는 왼쪽부터 세는 기준을 안내한다. 각 항목의 해제 버튼과 상단 `전체 비우기`, 재료 목록으로 돌아가는 뒤로가기를 제공하고, 해제·비우기는 DB의 재료를 변경하지 않는다. 목록을 비워도 화면을 강제로 닫지 않고 빈 상태를 표시하며, 추가 폼의 입력 초안과 섞이지 않게 한다.
- `여기로 이동`을 누르면 임시목록의 재료를 현재 열어둔 칸으로 한 트랜잭션에서 이동한다. 현재 칸에 이미 보관 중인 동일 ID의 재료는 위치 변경에서 제외하고, 전부 현재 칸의 재료이면 이동 버튼을 비활성화한다. 목적지에 같은 이름의 다른 재료가 있어도 각각의 ID·이름·수량·메모·유통기한·등록 건수를 유지한다. 저장 전에 최신 재료와 기존 ID·출발 칸·좌우 번호를 확인하고, 대상이 삭제되거나 출발 위치가 달라졌거나 목적지가 유효하지 않으면 전체 변경을 취소한다. 저장 중에는 중복 이동·추가·편집·삭제·목록 변경·뒤로가기·시트 종료를 막는다. 성공하면 모든 출발·도착 칸의 홈 배지와 목적지 목록을 갱신하고 임시목록을 비우며, 시트 내부에 공통 Toast로 `재료 N개를 이동했습니다.`를 약 2.9초 표시한다. 목록·도면의 열림·선택·크기는 유지한다. 실패하면 오류를 알리고 재료와 임시목록을 보존해 재시도·목록 수정을 허용한다. 기존 단일 이동 전용 하단 안내·취소 버튼·탭 덮개·시트 종료 후 목적지 선택 상태는 제거한다.
- 냉장고가 등록되지 않은 홈에는 옅은 민트색 원형 배경의 작은 냉장고 도식과 `우리 집 냉장고를 등록해 보세요` 안내, `문과 수납칸을 우리 집 냉장고 구조에 맞게 설정할 수 있어요.` 설명, 더하기 아이콘이 있는 넓은 `냉장고 등록하기` 버튼을 표시한다. 기존 등록 화면의 도식·공통 버튼을 재사용하고 전체 안내를 중앙보다 조금 위에 배치하며, 작은 화면이나 큰 글씨에서도 스크롤로 등록 버튼에 접근할 수 있게 한다. 조회 중·조회 실패 상태에는 등록 안내를 표시하지 않는다.
- 등록 버튼으로 전체 구성을 저장하며, 저장 중에는 중복 등록·입력 변경·이전 이동을 막는다. 실패하면 오류를 알리고 초안을 유지해 재시도할 수 있다. 등록·전체 수정 성공 시 `알림` 제목으로 각각 `냉장고를 등록했습니다.`·`냉장고를 수정했습니다.`를 표시하고, `확인`을 누르면 홈으로 돌아간다. 알림을 확인할 때까지 중복 저장·입력 변경·화면 이동을 막으며, 홈 진입 시 DB에서 등록 여부와 이름을 다시 확인한다.
- 홈 상단의 편집 아이콘으로 기존 등록 화면을 편집 모드로 연다. 저장된 이름·구조·문 수납·칸 구성을 불러와 수정하며, 불러오기 실패 시 기본 구성을 노출하거나 저장하지 않고 재시도할 수 있다. 수정 저장은 기존 냉장고와 남아 있는 위치의 ID를 유지하고 추가 위치에만 UUID를 발급한다. 전체 수정은 한 트랜잭션으로 처리하며, 실패하면 기존 데이터를 보존하고 초안을 유지한다. 취소하면 저장하지 않은 초안을 버리고, 저장 후에는 홈 도면을 다시 조회한다.
- 편집 모드의 냉장고 이름 입력 오른쪽에 `변경` 버튼을 표시한다. 이름만 별도로 저장하고 구조·위치 ID와 편집 중인 구조 초안은 유지하며, 성공 후에도 편집 화면에 머문다. 이름은 앞뒤 공백을 제거한 1~50자로 제한하고 비어 있거나 저장된 이름과 같으면 버튼을 비활성화한다. 저장 중에는 중복 저장·입력 변경·화면 이동을 막고, 실패하면 입력을 유지해 재시도한다. 이름을 별도로 저장한 뒤 편집을 취소해도 저장한 이름은 유지한다.
- 조회가 끝난 홈은 냉장고 등록 여부와 관계없이 상단에 `냉장고` 제목을 왼쪽 정렬해 표시한다. 등록된 냉장고의 이름은 제목 오른쪽에 보조 문구로 표시하고 두 글자의 기준선을 맞춘다. 편집 버튼은 헤더 오른쪽 끝에 표시하며 기본 헤더 높이를 유지한다. 긴 이름은 글자 크기를 줄이지 않고 한 줄에서 말줄임으로 표시하며 접근성 탐색에는 전체 이름을 전달한다. 저장된 구성은 등록 화면과 동일한 전체 도면·문 열림·중앙 보기 컴포넌트로 표시한다. 닫힌 전체 도면과 열린 본체·포켓의 크기·배율은 등록·편집 레이아웃을 공통 기준으로 사용하며, 홈의 표시 영역이 넓어져도 더 크게 확대하지 않는다. 홈에서 문을 열면 제목·냉장고 이름·안전 영역 여백을 포함한 전체 도면 영역을 기준으로 중앙에 표시하며, 떠 있는 도구 버튼의 높이는 제외하지 않는다. 바깥을 누르면 닫힌다. 수납 미사용 포켓은 X로 표시하고 서랍형은 포켓을 표시하지 않는다. 별도 단별 제목·선택 위치 문구는 추가하지 않는다.
- 홈의 열린 도면에서 본체는 편집 화면의 칸 구성과 같은 위치 단위 선택과 불투명 선택 배경을 사용하며 좌우 분할도 각각 선택한다. 선택한 위치 ID를 행 번호와 함께 관리하고 한 위치에만 선택 배경을 표시한다. 편집 툴바는 선택한 위치가 속한 행의 칸 구성을 조절하며, 분할 해제·선택한 칸 삭제 후에는 유효한 첫 위치로 돌아간다. 도어포켓은 밝은 전면판과 U자형 테두리로 된 수납함만 선택·강조하고 위쪽 빈 공간은 선택하지 않는다. 선택한 포켓은 전면 전체에 본체와 같은 불투명 선택색을 표시하며, 상단은 열린 모양을 유지한다. 본체·포켓 전체의 편집용 선택 테두리는 표시하지 않고 수납 미사용 포켓은 읽기 전용 X로 남긴다. 문을 열고 닫는 동안에는 칸 선택을 막으며, 도면을 닫거나 홈을 다시 조회하면 선택을 초기화한다. 등록·편집은 기존 영역 선택과 하단 편집 툴바를 유지한다.
- 기본 화면은 냉장고·장보기·더보기 3개 하단 탭으로 구성하며 React Navigation의 일반 Bottom Tabs를 공통 디자인으로 꾸민다. 크림색 바탕과 얇은 상단 경계선을 사용하고 선택·누름·길게 누름·호버 배경과 Android 리플 효과는 표시하지 않는다. 선택한 탭은 녹색 아이콘·문구로, 나머지 탭은 회색 윤곽 아이콘으로 구분한다. 더보기는 원 안의 가로 점 세 개 아이콘을 사용한다. 아이콘 크기는 24, 문구는 12로 아래에 배치하고 터치 높이는 48 이상을 확보한다. 버튼 안쪽 상단에 6의 여백을 두며 아이콘 슬롯 높이를 실제 아이콘 크기에 맞춰 경계선과 간격을 확보한다. 탭바의 기본 높이는 50이며 하단 안전 영역을 더하고, 본문은 탭바 위에 배치한다. 재료·이동 대기 시트가 열린 동안에는 탭 입력·접근성 탐색을 막고 종료 후 복원한다. 냉장고 등록은 탭 밖의 별도 화면으로 열어 등록 중에는 탭을 숨긴다. 장보기 목록 관리는 추후 구현한다.
- 더보기는 제목을 왼쪽에 배치하고, 화면 너비를 채운 카테고리 구분 영역과 하위 메뉴 목록으로 구성한다. 하단 탭과 같은 크림색 카테고리 영역과 공통 아이보리색 메뉴 배경을 얇은 가로선으로 구분하며 둥근 카드·오른쪽 화살표는 표시하지 않는다. 카테고리명은 14, 메뉴명은 16 크기로 표시하고 메뉴의 회색 아이콘·이름을 왼쪽에 정렬한다. 현재는 `설정` 카테고리에 언어 아이콘과 `언어` 버튼을 표시하며, 누르면 바로 언어 선택 화면으로 이동한다. 언어 선택 화면에서도 하단 탭을 유지하고 상단 뒤로가기·기기 뒤로가기·iOS 스와이프로 더보기 목록에 돌아간다. 문의·앱 정보 등은 기능이 준비되면 해당 카테고리에 추가하며, 동작하지 않는 메뉴나 빈 카테고리는 표시하지 않는다.
- `장보기 목록`은 구매 예정 항목, `장본리스트`는 구매 후 보관 위치를 지정하기 전의 임시 항목이다.
- 서랍형 본체는 내부 설정에서 합치기·칸 개수 조절·좌우 분할을 숨기고 냉장/냉동만 편집한다. 이웃 본체에서도 서랍형과 합치는 버튼을 숨긴다. 서랍형에는 보관 모드·여는 방식 카테고리만 표시한다. 왼쪽·오른쪽 열림에서 서랍형으로 전환하면 해당 본체의 칸 구성을 기본 1칸·분할 없음으로 초기화하고 선택 칸도 처음으로 돌린다. 여닫이형으로 되돌려도 초기화된 본체 칸을 사용하며, 문 수납 입력과 보관 모드는 유지한다.
- 본체의 칸 구조는 아이콘과 함께 `분할 없음 / 좌우 2칸`으로 선택한다. 내부 칸에는 서랍 손잡이를 표시하지 않고, 여는 방식이 서랍형인 본체에만 손잡이를 표시한다. 편집할 때 재료도 함께 조회하며, 조회에 실패하면 편집을 열지 않고 재시도한다. 재료의 보관 위치가 사라지거나 숨겨지는 단·문·칸 삭제, 칸 분할 변경, 본체 합치기·분리, 서랍형 전환, 문 수납 끄기는 저장 시점이 아닌 조작 시점에 안내하고 반영하지 않는다. 거부한 변경은 초안·선택 칸·중앙 보기를 유지하며, 홈에서 영향받는 재료를 먼저 이동·삭제한 후 다시 편집한다. 이름·보관 모드 변경, 기존 위치를 유지하는 추가, 빈 위치의 삭제·구조 변경은 허용하며 저장 시 DB의 위치 보호도 유지한다.
- 본체는 최대 4칸, 도어포켓은 최대 3칸까지 구성한다. 합치기·분리는 기존 칸 수를 제한 조건으로 삼지 않고 본체 칸을 기본값으로 초기화한다. 내부설정의 일반 문 손잡이는 세로 막대형으로 표시하고, 서랍형은 전면 상단 중앙에 윗변이 넓고 아랫변이 좁은 낮은 사다리꼴 홈으로 표시한다. 서랍 홈은 문 너비에 맞춰 배치하고 높이는 6으로 표시한다. 손잡이의 면과 경첩은 냉장에서는 연한 민트, 냉동에서는 연한 블루그레이를 사용하고 미설정 상태에서는 연한 중립 회색을 사용한다. 서랍 홈은 외곽선 없이 같은 색의 단색 면으로 표시한다. 경첩은 짧은 캡슐 형태로 표시하며 테두리·연결판·하이라이트는 표시하지 않는다. 경첩은 본체와 함께 이동하며, 문이 절반 열린 시점부터 완전히 열린 시점까지 투명도를 0에서 1로 바꾼다. 닫기 시작 시 갑자기 숨기지 않고 진행값에 따라 서서히 사라지게 한다.
- 내부설정의 외관·본체·포켓·공간 이름은 크림·민트·아이스블루 계열의 일러스트 표현을 공유한다. 직각 프레임·밝은 내부 면으로 영역을 구분하고 일반 문 손잡이·경첩은 둥근 형태로 단순화한다. 금속 질감과 입체 음영은 사용하지 않으며, 주변 화면 배경과 버튼의 색상은 유지한다.
- 도어포켓 수납함은 모드에 맞는 밝은 민트·아이스블루의 반투명 전면판과 U자형 테두리로 표현한다. 상단은 선과 굴곡 없이 열어 두고, 좌우·하단에는 같은 모드 색의 3px 테두리를 적용한다. 아래 양쪽 모서리만 12px로 둥글게 처리한다. 상단에 선처럼 보이는 음영이 생기지 않도록 전면판 그림자는 사용하지 않는다. 세로 리브선·양끝 막대·뒤쪽 테두리·보조선·하단 겹선은 표시하지 않는다. 수납함은 칸 크기에 맞춰 표시하며, 장식은 선택·스크롤 터치와 접근성 탐색을 가로채지 않는다. 도면과 칸의 전체 크기는 유지한다.
- 본체의 가로 칸 경계는 모드별 민트·아이스블루 선반으로 표시하고 그림자·윗면·겹선은 표시하지 않는다. 좌우 분할선은 가로 선반과 같은 모드별 민트·아이스블루 색의 두께 4 분할판으로 표시한다. 가로 선반과 좌우 분할선의 끝은 직각으로 처리하고 그림자는 표시하지 않는다. 구분선은 칸 사이 12의 공간 중앙에 배치해 양옆에 각각 4의 여백을 두고 선택 배경과 겹치지 않게 한다. 가로 선반 양끝은 칸의 좌우 끝에, 좌우 분할선 양끝은 칸의 상하 끝에 맞춰 외곽까지 연결하지 않는다. 최상단·최하단의 별도 연장 없이 모든 행에서 같은 높이의 좌우 분할선을 표시하고 가로 구분선 양끝을 포함한 바깥 상하좌우 여백은 구분선 중심까지의 반간격인 6으로 맞춘다. 구분선 바로 옆의 빈 여백 4에 선 두께의 절반 2를 더해 바깥과 중간 칸의 간격 기준을 통일한다. 구분선과 여백을 최소 편집 크기 계산에 포함해 각 수납 칸의 가로·세로 72 이상을 확보한다. 구분선은 터치와 접근성 탐색을 가로채지 않으며 칸 선택·스크롤 동작을 유지한다.
- 재료 변경 시 관련 알림을 갱신하고, 삭제·소비 완료 시 취소한다.
- 공유 데이터는 즉시 적용하지 않는다. 충돌을 강조한 화면에서 내용을 비교·선택하고, 최종 반영 전까지 기존 데이터를 유지한다.
- 백업 파일 병합에도 같은 충돌 처리 절차를 적용하며, 새 설치 환경에서도 복원할 수 있어야 한다.


## 비기능적 요구사항

| 구분 | 내용 |
| --- | --- |
| 오프라인 | 냉장고·재료·장보기의 핵심 기능은 인터넷과 서버 없이 동작한다. |
| 저장 안정성 | `expo-sqlite` 기반으로 관계·트랜잭션·DB 버전을 관리하고, 업데이트 시 기존 데이터를 보존한다. |
| 데이터 보호 | 공유 상대를 확인하고 데이터를 보호하며, 저장·병합·복원 실패나 잘못된 백업 파일로 기존 데이터가 손상되지 않아야 한다. |
| 데이터 일관성 | 냉장고 구조와 재료 위치 관계를 유지하고, 같은 공유 데이터를 중복 반영하지 않는다. |
| 권한 처리 | 카메라·알림 권한을 거절해도 수동 등록과 조회는 사용할 수 있다. |


## 추가 검토 사항

- P2P 통신 방식, 상대 기기 등록 절차와 공유 범위.
- 충돌 판정·선택 단위와 수정·삭제·구조 변경 간 충돌 처리.
- 클라우드 서버에 의존하지 않는 영수증 인식 방식과 사진 보관 여부.
- 입고 시 드래그앤드롭 지원 여부.
- 자동 장보기 등록 시점·수량·중복 방지 기준.
- 유통기한 임박 기준과 알림 시점·반복 주기, 소비 이력 보관 여부.
- 백업 암호화·암호 전달 방식과 전체 복원·병합 정책.
