# 냉장고 관리 앱 요구사항


## 프로젝트 개요 및 목적

별도 클라우드 서버 없이 로컬 DB로 동작하는 냉장고 관리 앱이다.
실제 냉장고 구조를 반영한 도면에서 재료의 보관 위치를 확인하고, 유통기한·장보기·부부 간 데이터 공유를 관리한다.


## 기능적 요구사항

| 구분 | 내용 |
| --- | --- |
| 기본 사용 | 로그인 없이 기기 내 냉장고 1대를 관리하며, 데이터는 앱 재실행 후에도 유지한다. |
| 냉장고 도면 | 냉장실·냉동실·문·본체·칸·서랍을 등록·편집하고, 위치를 선택하면 해당 재료 목록을 표시한다. |
| 재료 관리 | 재료명·수량·유통기한·위치를 관리하고, 등록·조회·수정·삭제·이동·소비 완료를 제공한다. |
| 영수증 인식 | 영수증을 카메라로 촬영해 구매 항목을 장본리스트에 임시 등록하고, 인식 결과를 수정할 수 있다. |
| 입고 처리 | 장본리스트 항목을 선택한 뒤 도면의 칸·서랍을 선택하고, 부족한 정보를 입력해 재료로 등록한다. |
| 장보기 관리 | 구매할 항목의 추가·수정·삭제·완료 처리를 제공하고, 구매 완료 항목을 장본리스트와 연결한다. |
| 자동 장보기 등록 | 유통기한을 기준으로 장보기 목록에 항목을 자동 등록한다. |
| 유통기한 알림 | 임박·만료 재료의 위치를 도면에 표시하고, 재료명·위치를 포함한 로컬 알림과 사용 재촉 알림을 제공한다. |
| P2P 공유 | 부부의 기기가 각자 관리한 데이터를 실시간 동기화 없이 주고받는다. 통신 방식은 별도 검토한다. |
| 충돌 처리 | 별도 화면에서 충돌 부분을 강조하고, 클릭하면 충돌 내용 중 하나를 선택해 최종 반영한다. |
| 백업·공유 | 설정에서 암호화된 백업 파일을 내보내거나 가져오고, 메신저로 공유할 수 있다. |


## 주요 정책 및 화면 흐름

- 현재 등록 대상은 일반 냉장고이다. 김치냉장고·뚜껑형 지원은 보류하고 조사 자료와 유형 데이터는 보관한다.
- 최초 등록은 단별 문 개수(1~2개)로 배치를 직접 구성하고, 내부 설정에서 여는 방식(왼쪽·오른쪽 열림·서랍형)·문 수납 사용 여부·같은 단의 본체 연결·칸·냉장/냉동을 정한다. 세로 문 합치기와 작은 보조 포켓은 제외한다.
- 내부 설정 도면은 기본 정보와 같은 문 배치로 닫힌 상태에서 시작한다. 문을 누르면 보기 선택 버튼 없이 연결된 본체와 도어 포켓이 함께 열리며 화면 중앙으로 이동한다. 문 한 개의 본체와 포켓은 같은 너비·높이로 표시하고, 공용 본체는 연결된 문 개수만큼 너비를 합산한다. 포켓은 여는 방향에 맞춰 본체 왼쪽·오른쪽에 나란히 배치하고 세로 경첩 두 개로 연결한다. 문 앞면과 뒷면은 같은 경첩을 기준으로 반대 면을 드러내며 회전한다. 열고 닫는 동안에도 본체 프레임과 빈 안쪽 면은 문 뒤에 유지하고, 본체·포켓의 칸과 내부 배지는 문이 완전히 열린 뒤 경첩과 함께 표시한다. 닫기 시작과 동시에 내부 내용과 경첩을 숨긴다. `본체 / 포켓` 구분 배지와 각 영역의 보관 모드 배지는 내부 상단에 두고, 칸 이름과 겹치지 않게 공간을 확보한다. 서랍 전면은 아래로 밀려 열린다. 스크롤 밖의 레이어에서 열림·이동을 함께 가감속하고 문이 완전히 열린 상태에서 도면 바깥 배경을 누르면 원래 자리로 복귀하며 닫힌다. 도면의 별도 `닫기` 버튼은 표시하지 않고, 도면 내부·경첩·하단 툴바 조작은 외부 닫기를 실행하지 않는다. 기본 도면의 본체 라인·폭은 유지하고 높이는 540 이내에서 남은 화면 공간에 맞추며, 중앙 보기 동안 주변 도면의 스크롤·터치·접근성 탐색을 막는다.
- 중앙의 본체·포켓을 각각 누르면 해당 영역을 선택해 기존 하단 툴바와 내부 설정 패널로 편집한다. 수납을 끈 포켓은 X 표시로 남겨 선택 후 툴바에서 다시 켤 수 있게 하고, 서랍형에는 포켓을 표시하지 않는다. 합치기·분리 후에는 연결된 본체·포켓 배치와 복귀 위치를 다시 계산한다. 보기 상태는 등록 초안과 분리해 도면을 닫아도 기존 입력을 유지한다.
- 중앙 위치는 헤더·툴바 사이의 확정된 레이아웃 크기로 계산하며, 내부 설정 패널을 열거나 닫아도 표시 영역의 크기가 같으면 위치를 유지한다. 여는 방식 선택지는 툴바 위에 겹쳐 표시하고 도면의 표시 영역을 줄이지 않는다. 열린 도면의 여백을 중복 적용하지 않고 실제 테두리를 기준으로 경첩 양끝을 맞춘다.
- 열고 닫는 중에는 원근 회전으로 커지는 문의 끝이 단계 표시 영역에서 잘리지 않게 한다. 이때 다른 단계의 화면은 숨기고, 전체 도면으로 복귀하면 단계 전환의 잘림을 복원한다.
- 하단 툴바 공간은 중앙 보기 영역에서만 확보한다. 배경 전체 도면의 스크롤 영역은 툴바가 나타나거나 숨겨져도 같은 높이·스크롤 위치를 유지해 아래쪽 문이 잘리지 않게 한다.
- 중앙 보기의 배경 덮개는 툴바가 숨겨진 하단 공간을 포함한 전체 도면 화면을 채운다. 도면의 중앙 위치를 계산하는 영역과 배경을 덮는 영역을 구분해 하단에 색상 띠가 생기지 않게 한다.
- 내부 설정의 도면 화면은 상하 스크롤·튕김 없이 고정하고, 작은 화면에서는 모든 단이 들어오도록 남은 높이에 맞춘다. 기본 정보 입력 화면과 하단 칸 편집 패널은 스크롤을 유지한다.
- 본체 합치기는 같은 단에서 도면상 서로 맞닿은 본체끼리 허용하며, 왼쪽·오른쪽 어느 본체를 선택해도 가능하다. 문 방향·열림 상태·수납 사용 여부는 본체끼리의 맞닿음에 영향을 주지 않는다. 합치지 않은 본체 선택 시 `합치기` 버튼은 항상 표시하고, 이웃 본체가 없거나 합친 칸 수가 최대치를 넘으면 비활성화한다. 합칠 때 칸의 좌우 순서와 선택한 본체의 식별자를 유지하고, 분리할 때는 복귀할 문에 기존 식별자를 남겨 중앙 보기와 복귀 위치를 유지한다. 합친 본체는 `합치기` 대신 `분리`만 표시한다.
- 합친 본체의 문은 기존 여는 방식과 관계없이 왼쪽 문은 왼쪽 열림, 오른쪽 문은 오른쪽 열림으로 바꿔 본체 양쪽에 배치한다. 어느 문을 눌러도 닫힌 외관과 열고 닫는 동안의 양쪽 문에 선택 표시를 함께 적용하며, 열린 뒤 본체·도어포켓은 개별 선택한다. 문 수납 사용 여부와 칸 입력은 유지한다. 합친 본체는 `여는 방식` 버튼을 비활성화하고 선택 메뉴를 숨긴다. 본체를 분리하면 버튼을 다시 활성화하고 기존 메뉴 열림 상태를 복원한다.
- 본체를 분리할 때는 기존 칸의 순서·이름·서랍 구조를 유지해 나눠 배치한다. 분리할 본체보다 칸이 적을 때만 기본 칸을 추가하며, 합치기·분리 반복으로 칸이 불필요하게 늘어나지 않아야 한다.
- 최초 등록의 단계 이동 버튼은 상단 헤더에 고정한다. 기본 정보는 왼쪽 `취소`·오른쪽 `다음`, 내부 설정은 왼쪽 `이전`·오른쪽 `등록`을 표시한다.
- 문 수납은 `문 수납` 문구 옆의 스위치로 사용 여부를 표시하고 변경한다. 수납을 끈 문은 `내부 설정` 버튼을 비활성화하고, 수납을 켠 문은 수납칸만 편집한다. 보관 모드는 본체 내부 설정에서만 변경하며, 새 본체의 기본값은 냉장이다.
- 등록 도면에서 선택한 문·본체에만 냉장은 연한 초록, 냉동은 연한 파란 배경을 적용한다. 보관 모드 배지는 유지하며, 선택 영역은 모드 색상의 테두리에서 바깥으로 옅게 퍼지는 효과로 강조한다. 수납을 끈 문도 연결된 본체의 모드를 따라 동일하게 적용한다. 선택하지 않았거나 보관 모드 미선택 상태이면 기본 배경을 유지하고, 보관 모드 미선택 상태의 선택 테두리는 기본 진한 색을 쓴다. 내부 설정 패널의 미리보기에는 보관 모드 배경을 적용하지 않는다.
- 닫힌 전체 도면의 보관 모드 배지는 문 앞면의 테두리 안쪽 오른쪽 상단에 표시한다. 배지는 열림 시작 시 사라지지 않고 문 앞면과 함께 회전하며, 연결된 본체당 하나만 표시한다. 문이 완전히 열리면 본체와 포켓 모두 내부 상단에 냉장 온도계·냉동 눈송이를 표시하며, 포켓은 수납 사용 여부와 관계없이 연결된 본체의 모드를 따른다. 모드 배지와 구분 배지는 좁은 도면에서도 겹치지 않게 배치하고, 모드 미선택 상태에서는 모드 배지를 표시하지 않는다.
- 내부 설정의 전체 도면 화면에서는 툴바를 표시하지 않는다. 문이 완전히 열린 동안에만 해당 본체·포켓에서 선택한 영역의 툴바를 화면 하단에 표시하고, 열고 닫는 중에는 숨기고 조작·접근성 탐색을 막는다. 이동 중에도 툴바 공간을 유지해 중앙 도면이 튀지 않게 한다. 선택 위치는 하단 내부 설정 패널의 제목에 표시한다. `여는 방식` 버튼과 메뉴는 본체 선택 시에만 표시해 연결된 문의 선택지를 툴바 위에 펼친다. 메뉴의 열림 상태는 다른 본체를 선택하거나 본체를 합치기·분리해도 보관하고, 내부 설정 패널을 닫은 뒤에도 유지한다. 포켓 선택 중에는 여는 방식 버튼과 메뉴를 모두 숨기며, 합치지 않은 본체를 다시 선택하면 기존의 열린 상태를 복원한다. `닫기` 또는 `여는 방식` 버튼을 다시 눌러 메뉴를 닫는다. 기기 뒤로가기·접근성 닫기·단계 이동도 기존 흐름을 유지한다. `내부 설정`은 하단 패널에서 칸·보관 모드를 편집한다. 변경은 초안에 즉시 반영하고 선택지·패널을 닫아도 입력을 유지한다.
- 설정 패널 상단에는 선택 영역의 축소 미리보기를 고정한다. 문·본체 모두 오른쪽 위에 냉장·냉동 버튼, 아래에 기본 정보의 문 개수와 같은 `− 칸 N개 +` 조절과 최대 칸 개수 안내 문구를 묶어 상하 양끝으로 배치한다. 문에서는 연결된 본체의 보관 모드를 선택 상태로 표시하고 냉장·냉동 버튼은 비활성화한다. 보관 모드 제목은 표시하지 않고, 아래 스크롤 영역에서 개별 칸을 편집한다. 배경은 제자리에서 흐려지고 패널만 아래에서 올라온다.
- 기본 흐름: `첫 실행 → 냉장고 등록 → 홈 도면 → 위치 선택 → 재료 목록·관리`.
- 홈은 냉장고·장보기·설정으로 구성하며, 기존 `fridge-manager`의 도면과 사용 흐름을 참고한다.
- `장보기 목록`은 구매 예정 항목, `장본리스트`는 구매 후 보관 위치를 지정하기 전의 임시 항목이다.
- 본체의 칸 구조는 아이콘과 함께 `분할 없음 / 좌우 2칸`으로 선택한다. 내부 칸에는 서랍 손잡이를 표시하지 않고, 여는 방식이 서랍형인 본체에만 손잡이를 표시한다. 재료가 있는 위치의 삭제·구조 변경은 재료를 먼저 이동·삭제한 후 처리한다.
- 본체와 포켓은 각각 최대 4칸까지 구성하고, 본체 합치기도 합산 4칸까지만 허용한다. 일반 문과 서랍형의 손잡이는 같은 크기·모양의 막대형으로 표시하며, 일반 문은 세로·서랍형은 가로로 배치한다. 경첩은 양쪽 연결판과 마디가 있는 회전축으로 표현해 손잡이와 구분한다. 경첩은 문이 완전히 열린 동안에만 표시하고, 닫기 시작과 동시에 숨긴다.
- 외관·본체·포켓·선반·배지·축소 미리보기는 왼쪽 위 하이라이트와 오른쪽 아래 음영을 공유한다. 외관은 볼록한 면, 수납 공간은 안쪽 음영, 선반 경계는 얇은 단차로 표현해 손잡이·경첩과 입체감을 맞춘다.
- 재료 변경 시 관련 알림을 갱신하고, 삭제·소비 완료 시 취소한다.
- 공유 데이터는 즉시 적용하지 않는다. 충돌을 강조한 화면에서 내용을 비교·선택하고, 최종 반영 전까지 기존 데이터를 유지한다.
- 백업 파일 병합에도 같은 충돌 처리 절차를 적용하며, 새 설치 환경에서도 복원할 수 있어야 한다.


## 비기능적 요구사항

| 구분 | 내용 |
| --- | --- |
| 오프라인 | 냉장고·재료·장보기의 핵심 기능은 인터넷과 서버 없이 동작한다. |
| 저장 안정성 | `expo-sqlite` 기반으로 관계·트랜잭션·DB 버전을 관리하고, 업데이트 시 기존 데이터를 보존한다. |
| 데이터 보호 | 공유 상대를 확인하고 데이터를 보호하며, 저장·병합·복원 실패나 잘못된 백업 파일로 기존 데이터가 손상되지 않아야 한다. |
| 데이터 일관성 | 냉장고 구조와 재료 위치 관계를 유지하고, 같은 공유 데이터를 중복 반영하지 않는다. |
| 권한 처리 | 카메라·알림 권한을 거절해도 수동 등록과 조회는 사용할 수 있다. |


## 추가 검토 사항

- P2P 통신 방식, 상대 기기 등록 절차와 공유 범위.
- 충돌 판정·선택 단위와 수정·삭제·구조 변경 간 충돌 처리.
- 클라우드 서버에 의존하지 않는 영수증 인식 방식과 사진 보관 여부.
- 입고 시 드래그앤드롭 지원 여부.
- 자동 장보기 등록 시점·수량·중복 방지 기준.
- 유통기한 필수 여부, 임박 기준과 알림 시점·반복 주기, 소비 이력 보관 여부.
- 백업 암호화·암호 전달 방식과 전체 복원·병합 정책.
